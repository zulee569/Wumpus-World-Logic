# Wumpus World Logic Agent - Setup Guide

This guide will help you setup and run the Wumpus World Logic Agent on your local machine.

## 1. Install Python
If you don't have Python installed, download it from [python.org](https://www.python.org/downloads/). 
**Important:** During installation, make sure to check the box that says **"Add Python to PATH"**.

## 2. Install Required Libraries
You need to install the following Python libraries for the code to work. Open your terminal or PowerShell and run these commands one by one:

pip install streamlit
pip install numpy
pip install sympy
